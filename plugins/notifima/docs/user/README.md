# Notifima User Guides

Plain-language guides for store owners using Notifima — the WooCommerce back-in-stock notifier and stock manager. Each guide first explains **what a feature does and why it matters**, then shows **how to use it** and explains every setting.

Looking for code-level detail instead? See the [developer docs](../developer/README.md).

## Read in this order

```
1. GETTING-STARTED  ──►  2. SETTINGS (Automation)  ──►  3. Pick a guide below
```

| Step | Guide | Use it to |
|---|---|---|
| 1 | [GETTING-STARTED](GETTING-STARTED.md) | Install the plugin, understand how a waitlist works end to end, and find your way around the admin menu |
| 2 | [SETTINGS](SETTINGS.md) | Find any setting across all four Settings tabs |

## How every guide is built

Each guide has the same shape so you can skim it:

1. **What it does** — the feature in plain words.
2. **Why it matters** — what you gain, or risk if you ignore it.
3. **How to use it** — numbered steps.
4. **Settings explained** — a table saying what each setting does and why you might use it, where relevant.
5. **Related** — where to go next.

Features marked **[PRO]** in a guide require [Notifima Pro](https://notifima.com/pricing/?utm_source=wporg&utm_medium=plugindescription&utm_campaign=notifimawporg) — they're listed so you know they exist, not because the free plugin can do them.
