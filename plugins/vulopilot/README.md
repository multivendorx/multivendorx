VuloPilot is an AI-powered WordPress optimization plugin that helps improve SEO, site health, website performance, accessibility, content quality, and WooCommerce stores from one intelligent dashboard.

## Description ##

🚀 **VuloPilot** is an all-in-one AI-powered website optimization and maintenance plugin for WordPress.

Instead of installing multiple plugins for SEO, performance, accessibility, website monitoring, maintenance, and AI content, VuloPilot combines everything into one modern platform.

Whether you manage a business website, WooCommerce store, blog, LMS, membership site, or agency, VuloPilot continuously analyzes your website and provides actionable insights to improve search visibility, performance, user experience, and overall website health.

## Installation ##

1. Upload the plugin to the `/wp-content/plugins/` directory.
2. Activate the plugin through the WordPress Plugins screen.
3. Navigate to **VuloPilot** in the WordPress admin menu.
4. Run your first website scan.
5. (Optional) Connect your preferred AI provider to enable AI-powered suggestions.

## Frequently Asked Questions ##

### Does VuloPilot require AI? ###

No.

Website scanning, SEO analysis, performance monitoring, accessibility checks, maintenance tools, and reports work without AI.

AI is used only for advanced recommendations and content generation.

### Which AI providers are supported? ###

VuloPilot supports:

* OpenAI
* Anthropic Claude
* Google Gemini
* OpenRouter
* Ollama
* Groq

### Can I use my own API key? ###

Yes.

The free version supports Bring Your Own API Key (BYOK).

### Does VuloPilot work with WooCommerce? ###

Yes.

WooCommerce optimization features are available, with additional AI-powered capabilities in VuloPilot Pro.

### Does VuloPilot automatically modify my website? ###

No.

By default, VuloPilot provides recommendations and requires your approval before making changes.
